# CSS Bouncy Castle

A fully animated 3D scene built entirely with HTML and CSS — no JavaScript or WebGL. A creative experiment pushing CSS transforms to their limits.

---

## Features

- Animated 3D bouncy castle scene rendered with pure CSS
- Every object built from a six-face box composed with `transform: rotate3d` and `translate3d`
- Keyframe-driven animation — no runtime JavaScript
- Sass-based stylesheet pipeline with reusable `box`, `face`, and `pivot` partials

---

## Technologies Used

- Vite
- Sass
- HTML and CSS (no runtime JavaScript)

---

## Getting Started

### Installation

```bash
pnpm install
```

### Scripts

- `pnpm dev` - Start dev server
- `pnpm build` - Build for production
- `pnpm preview` - Preview production build locally
